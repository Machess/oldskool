# Oldskool

Launch page for Oldskool, a studio making educational games and stories for children.

Plain HTML, CSS and JavaScript. No build step: host the files as they are.

- `index.html` – the page
- `style.css` – the look (colours and fonts are variables at the top)
- `script.js` – phone menu, sign-up form, the sample question

## Before going live

- Set `SIGNUP_ENDPOINT` at the top of `script.js` to your mailing-list form URL.
- Replace the placeholders in `index.html`: `[LAUNCH DATE]`, `[PLATFORMS]`, `[AGE RANGE]`, `[CONTACT EMAIL]`.
- Swap the `[Studio key art]` box in the hero for an image.
- Add a privacy page and link it from the footer.
